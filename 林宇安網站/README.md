# 林宇安｜官方音樂網站 V2.0

## 晨霧微光・電影敘事・柔霧玻璃

此網站在「林宇安網站」子資料夾獨立運作，不變動根目錄 AURORA AUDIO 的既有系統。

- 正式網站：https://lin-yu-an-music.vercel.app
- 原始碼：qhero70/aurora-audio / 林宇安網站
- 版本：V2.0.0（2026-10-29）
- 主色：#2B59C3、#253C78、#D36582、#FFEECF、#C9A690

## 功能
五個頁籤（首頁、音樂、寫真、MV、關於）、三首原創 MP3 雲端同源串流、播放暫停/切換/進度/音量/三段 EQ、由真實頻譜分析器提供的動態視覺化、相簿四類篩選與鍵盤可操作的全螢幕燈箱、響應式手機底部播放器、PWA 介面快取與安全更新。

音訊由「api/音樂.js」提供三首曲目的白名單串流。僅使用已取得公開讀取權限的 Drive MP3，不保存任何帳號憑證。Google Drive 分享權限建議設為「知道連結的任何人可檢視」，不要保留 anyone:writer。

## 素材與限制
已使用相同歌手的七張既有素材。指定的五張全身生活照仍待提供符合人物一致性的新圖，**不得冒用現有不同景別照片為新生活照**。正式 MV 未公開前不顯示可播放影片。

## 更新驗收
1. 在 GitHub 查核提交是否只變更「林宇安網站/」。
2. Vercel Production 狀態 READY 與實際網頁 200。
3. 逐首確認 api/音樂?track=0/1/2，包含 Range 請求 206。
4. iPhone Safari 實測播放、暫停、拖曳進度、EQ 與切換頁籤持續播放。
5. 測試 360、390、430、768、1440px，不得橫向溢出。
6. 安裝 PWA，離線重新開啟基本頁面，確認音樂離線不保證播放。
7. 用真實使用者裝置測量 LCP/CLS，再判定是否達標。
