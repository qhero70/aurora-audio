# 林宇安｜官方音樂網站

本網站以繁體中文撰寫，位於 `林宇安網站/`，**不修改**原有 aurora-audio 音訊播放器。

功能：首頁／三首歌曲／歌手寫真／MV 預留／關於、手機全尺寸響應式、播放器上一首下一首、進度、音量、三段 EQ、PWA 離線介面。

## 歌曲來源
請將以下由本人原創的三首 MP3 放在 `音樂/` 資料夾，網站便能穩定直接播放：
- 來安慰我吧.mp3
- 把心門打開混音版.mp3
- 把心門關起來_processed.mp3

當 MP3 尚未上傳時，播放器會嘗試連結 Google Drive（可能受分享權限／跨網域限制），也可在音樂頁選擇本機 MP3 作暫時播放。

## 發布
Vercel 連結 `qhero70/aurora-audio`，專案根目錄設為 `林宇安網站`，Framework 選 Other（純靜態網站），Output Directory 留空。
