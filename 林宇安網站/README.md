# 林宇安官方音樂網站 V2.1 — JI* GT AUDIO ULTRA
正式網站：https://lin-yu-an-music.vercel.app
資料夾：林宇安網站
日期：2026-10-29

僅改動林宇安網站。保留三首作品、同源雲端 MP3 串流、原有網站風格與其他儲存庫內容。

音樂頁新增三個工作站頁籤：播放控制與視覺、聲學等化器、DSP 音效與播放清單。
一鍵天籟鎖定為十段 EQ +7/+5/+2/0/+1.5/+3.5/+4.5/+3/+1/-3 dB，頻率 32/64/125/250/500/1000/2000/4000/8000/16000 Hz。
空間 StereoPanner +0.75；混響濕聲 0.35；真空管 Waveshaper 驅動 45，低通 14kHz；壓縮器及輸出 Gain 0.56 作為過載風險控制。
上述音效改變實際聲音，但不會提高 MP3 位元率、不能保證所有耳機/裝置達到「完美音質」。
全站底部播放與工作站共用單一 Audio 元素及 AudioContext。播放時依瀏覽器點擊政策啟動。
頻譜五種樣式：柱狀、時域波形、圓環、矩陣、光譜，直接分析音訊而非假數據。
相簿、MV 與 PWA 保留；音訊 Range 繞過 Service Worker 快取。
部署 READY 與三首音訊 probe 可由正式端驗證；iPhone Safari 實機聽感與多裝置負載仍需驗收。

可載入同名 MP3 替換三首正式音檔，也可將 MP3/WAV/M4A/MP4 暫加到當前工作階段播放清單（不會上傳）。瀏覽器不支援的 MP4 編碼可能無法解碼。
